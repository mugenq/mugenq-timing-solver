# Cycle 16: objective-consistency audit

The latest persisted Cycle 15 bundle and the persisted semi-Markov solver were inspected.

## New finding

There is a production-level objective mismatch that must be fixed before a real residual benchmark is meaningful.

The current solver:

1. sweeps 70 DP parameter combinations;
2. uses DP `change_penalty` values 0, .002, .005, .010, .018;
3. then selects `audio_selected` with a different fixed objective: `raw - .85*sections - .014*interval_change - .04*weak`.

That final selector contains no calibrated residual term.

Therefore simply adding residual evidence inside the DP is insufficient: a residual-favored path can be generated by the DP and then rejected by the old selector because the selector cannot see the new evidence.

## Quantitative scale

For the six persisted controlled `that day` reset geometries, at frozen `RESET_WEIGHT=0.055`:

- summed positive residual contribution: 1.499400
- corresponding fixed .014/ms interval-change cost: 0.350000
- net contribution after that physical change cost: 1.149400

The existing 8-section audio-selected path has 28.0 ms of adjacent half-beat interval change after 0.5-ms quantization, worth 0.392 under the selector's fixed .014/ms penalty.

The reset contribution is therefore not numerically negligible relative to the existing path-selection regularizer.

## Implementation direction

Use one frozen audio-only objective for both recurrence and final selection:

- section penalty: .85
- physical interval-change penalty: .014/ms
- weak-node penalty: .04
- calibrated residual weight: .055

A controlled test confirms that two otherwise identical paths differing only in reset evidence are indistinguishable under the old selector but correctly ordered under the unified objective.

## Blocker

The real `that day` dense residual arrays / audio are still absent from the persisted research bundle, so no end-to-end accuracy number is fabricated here. Once those arrays exist, the first real benchmark should use the unified frozen objective rather than the old parameter sweep plus mismatched selector.
